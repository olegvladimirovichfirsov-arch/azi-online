# Ази Онлайн — карточная игра в браузере

Лендинг игры «Ази»: [играть](https://azi-game.onrender.com/), [бот в Telegram](https://t.me/azi_card_bot), [канал](https://t.me/azi_card).

- Бесплатная карточная игра: три взятки, козырь и торги.
- 2–6 игроков за столом, игра с друзьями по ссылке.
- Без установки: браузер и Telegram Mini App.
- Игровые фишки, без реальных ставок и депозитов.

Правила: [правила игры Ази](https://azi-game.onrender.com/pravila) · [как играть](https://azi-game.onrender.com/kak-igrat)
